# سجل العمل: مراجعة المشروع وإصلاحه ونشره (22 نوفمبر 2026)

هذا الملف يوثّق كل ما تم في جلسة العمل مع Claude: من تحليل المشروع، إلى تحديث المكتبات وسد الثغرات، وحل مشكلة الحجب، ونشره على Vercel.

## 1. تحليل المشروع (نقطة البداية)

**ما هو المشروع:** منصة لجمع العملاء المحتملين من البيانات العامة على إنستقرام. لها نواة واحدة تعمل من أربع واجهات:
- الطرفية (CLI)
- REST API
- خادم MCP لـ Claude
- لوحة ويب

وتصدّر النتائج إلى Google Sheets أو CSV أو XLSX.

**الهيكل:**

| المجلد | الدور |
|---|---|
| `apps/web` | Next.js: اللوحة، و `/api/v1`، و `/api/mcp`، و OAuth، و cron، و webhook تلكرام. هذا ما يُنشر على Vercel |
| `apps/cli` | أمر `scrapers` في الطرفية، ويشمل خادم MCP المحلي |
| `packages/core` | المهام والاستخراج والموجّه بين المزوّدين والإيقاف |
| `packages/providers` | العامل (Instaloader) و Apify و Graph API |
| `packages/exporters` | CSV و XLSX و Google Sheets |
| `packages/ai` | التقييم بـ Claude |
| `packages/mcp` | أدوات وموارد MCP |
| `packages/api` | REST API (Hono + OpenAPI)، ويُخدَم من داخل `apps/web` |
| `packages/runtime` | يجمع كل شيء من متغيرات البيئة |
| `packages/db` | مخطط Drizzle والـ migrations |
| `services/ig-worker` | Python 3.14 + FastAPI + Instaloader، ويعمل خارج Vercel |

**التقييم:**

نقاط القوة:
- تصميم بنواة واحدة.
- أدوات حديثة: Turbo و Drizzle و pg-boss و Hono.
- اهتمام بالخصوصية: قائمة إيقاف مشفّرة، ومدة احتفاظ، و RLS، وسجل نشاط.
- اختبارات قوية: وحدة، وتكامل على Postgres، و e2e للوحة.
- CI فيه فحص أمني.

نقاط الانتباه:
- المخاطرة القانونية: شروط Meta وقوانين حماية البيانات.
- مكتبة `exceljs` مهجورة.
- إنستقرام يحجب عناوين السحابة.

**المنصة الموصى بها:**
- Vercel للوحة والـ API و MCP.
- Neon لقاعدة البيانات.
- العامل على جهاز في البيت.

## 4. حل حجب إنستقرام

**المشكلة:** إنستقرام يحجب عناوين مراكز البيانات (Vercel و Railway وأي سحابة).

**الحل: ثلاث طبقات تعمل تلقائياً**

1. **العامل على جهاز في البيت عبر Cloudflare Tunnel** (`deploy/home-worker/compose.yml`):
   - عنوان البيت سكني، وإنستقرام يحجبه أقل بكثير.
   - يعمل بأمر واحد: `docker compose up -d`. لا يحتاج فتح منافذ في الراوتر، وعنوان البيت لا يظهر لأحد، وهو مجاني.
2. **تدوير البروكسيات داخل العامل** (`services/ig-worker/src/ig_worker/pool.py`):
   - يقرأ `PROXY_URLS` (عدة بروكسيات مفصولة بفواصل)، ويبدأ بعنوان البيت.
   - المخرج المحجوب يرتاح 15 دقيقة، وتتضاعف المدة مع كل حجب متتالٍ حتى 6 ساعات، وينتقل الطلب نفسه للمخرج التالي.
   - لا يُبلغ العامل عن فشل إلا إذا كانت كل المخارج ترتاح.
3. **التحويل بين المزوّدين** (كان موجوداً أصلاً): عند حجب العامل كلياً تنتقل المهمة إلى Graph API أو Apify، ثم تعود للعامل المجاني.

**مراقبة العامل:**
- `/health`: عام، ويعرض الأعداد فقط.
- `/status`: يحتاج `x-worker-secret`، ويعرض حالة كل مخرج بدون كلمات مرور البروكسيات.

**الدليل الكامل:** [docs/HOME-WORKER.md](HOME-WORKER.md)

## 5-هـ. المرحلة الأولى من التطوير العميق: حلقة العائد والسرعة (Pull Request #19)

**حلقة العائد:** المنصة صارت تقيس المال لا الأعداد فقط.
- `leads.deal_value` و`deal_at`: قيمة الصفقة تُسجَّل من صفحة العميل («قيمة الصفقة») أو من Claude (`set_deal`).
- `jobs.cost_usd` صار يُسجَّل فعلاً: تكلفة الاكتشاف وكل حساب جديد يُقرأ، من سعر المزوّد (Apify 2.5$ لكل 1000 افتراضياً)، والمحفوظ مسبقاً بلا تكلفة.
- صفحة «العائد» (`/insights`): لكل مصدر الحسابات، والتواصل، والمهتمون، والعملاء، والإيراد، والتكلفة، والعائد لكل دولار، ونسبة الإغلاق، وأيام الإغلاق، مع توصية (ضاعِف / استمر / أوقف).
- الحساب الموجود عند أكثر من منافس يُحسب لكل منهم، وقيمة صفقته تُقسم بالتساوي.
- أداة `source_performance` لـ Claude.

**السرعة:** قِسنا كل صفحة محلياً مع 400 عميل: بين 20 و110 ملّي ثانية، أي أن الكود ليس البطيء. البطء في الإنتاج من بدء التشغيل البارد:
- طابور المهام (pg-boss) كان يفتح اتصالاً ثانياً غير مجمّع، ويشغّل استعلامات البدء مع كل تشغيل بارد، حتى لعرض صفحة. الآن يبدأ عند أول مهمة فقط (`lazyBoss`).
- ذاكرة المتصفح للصفحات (`staleTimes`): الرجوع لصفحة زرتها خلال 30 ثانية فوري.
- يبقى سبب لا يُحل بالكود: Neon المجاني يوقف قاعدة البيانات بعد 5 دقائق خمول، فأول طلب بعدها يأخذ ثانية إلى ثانيتين. إبقاؤها مستيقظة يستهلك ساعات الحوسبة المجانية (191 ساعة شهرياً) ولا ننصح به.

## 5-و. المرحلة الثانية: الذاكرة بالمعنى والتاريخ (ضمن Pull Request #19)

اخترنا الطريق الذي يعمل على الخطة المجانية بلا مفتاح إضافي: pgvector غير متاح في قاعدة الاختبار ولا في فحوص GitHub، وAnthropic لا تقدّم واجهة embeddings.
