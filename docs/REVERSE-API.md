# نافذة reverse-api-engineer: تحويل أي موقع إلى API

نافذة مستقلة في المنصة (`/reverse-api-engineer`) تشغّل أداة [reverse-api-engineer](https://github.com/kalil0321/reverse-api-engineer) (رخصة MIT) **على جهازك فقط**. تفتح الأداة الموقع في متصفح، وتسجّل طلبات الشبكة التي يرسلها، ثم يكتب نموذج الذكاء الاصطناعي الذي تختاره كوداً جاهزاً (TypeScript أو Python أو غيرهما) يستدعي نفس الواجهات مباشرة.

## الاستهلاك

| الخدمة | ما تستهلكه النافذة |
|---|---|
| Vercel | لا شيء تقريباً: النافذة صفحة ثابتة مبنية مسبقاً تُقدَّم من الـ CDN بلا أي دالة |
| قاعدة البيانات (Neon) | لا شيء: لا يُحفظ شيء في المنصة |
| Apify | لا شيء |
| جهازك | متصفح وقت التشغيل، ومساحة صغيرة للملفات |
| مزوّد الذكاء الاصطناعي | التكلفة الوحيدة، ويمكن أن تكون صفراً بنموذج OpenCode المجاني أو Ollama على جهازك |

المتصفح يكلّم «الجسر» على جهازك مباشرة (`http://127.0.0.1:7466`)، ولا يمر أي طلب بخوادم المنصة.

## التثبيت (مرة واحدة)

1. **Python 3.11** فما فوق، و **Node.js 20** فما فوق.
2. ثبّت الأداة:
   ```bash
   uv tool install reverse-api-engineer
   ```
   (أو `pip install reverse-api-engineer`. للتصفح اليدوي: `uv tool install "reverse-api-engineer[manual]"` ثم `playwright install chromium`.)
3. نزّل الجسر من النافذة (`rae-bridge.py`، Python فقط بلا مكتبات) وشغّله:
   ```bash
   python rae-bridge.py --origin https://<موقعك>.vercel.app
   ```
4. الصق **رمز الربط** الذي يطبعه في النافذة واضغط «اتصل».

الأجهزة المدعومة من الأداة الأصلية: ويندوز 64 بت، وماك بمعالج Apple، ولينكس. استعمل Chrome أو Edge (Safari قد يمنع الاتصال بالجهاز المحلي). لا يعمل من الهاتف.

## المزوّدون

| المزوّد | الطريقة | المفتاح |
|---|---|---|
| OpenCode (مجاني) | `sdk: opencode` بنموذج big-pickle | لا يحتاج |
| Anthropic Claude | `sdk: claude` | `ANTHROPIC_API_KEY` أو تسجيل دخول Claude Code |
| OpenAI | عبر OpenCode | `OPENAI_API_KEY` |
| OpenAI Codex (حساب ChatGPT) | `sdk: codex` | `codex login` |
| Google Gemini | عبر OpenCode | `GOOGLE_GENERATIVE_AI_API_KEY` |
| DeepSeek، xAI، Mistral، Groq، OpenRouter | عبر OpenCode | مفتاح كل شركة |
| GitHub Copilot | `sdk: copilot` | `GITHUB_COPILOT_TOKEN` |
| Cursor | `sdk: cursor` | `CURSOR_API_KEY` |
| Ollama (على جهازك) | عبر OpenCode | لا يحتاج |

الإعدادات تُكتب في `~/.reverse-api/config.json` (نفس ملف الأداة الأصلية)، والمفاتيح في `~/.spir-rae/keys.json` (مقروء لك وحدك) وتُمرَّر للأداة كمتغيرات بيئة. لا تُرسل للمنصة ولا تُعاد للنافذة.

## ما في النافذة

- **تشغيل جديد:** رابط الموقع والهدف، مع «فحص مسبق» بلا تكلفة (`agent --dry-run`)، ثم التشغيل (`agent --json-stream`) مع تقدمه مباشرة والتكلفة.
- **التشغيلات السابقة:** (`list`) وفتح أي تشغيل لعرض ملفاته ونسخها وتنزيلها.
- **تحسين الكود** من نفس التسجيل بلا تصفح جديد (`engineer`، مع خيار البدء من جديد `--fresh`).
- **MCP محلي:** الجسر نفسه خادم MCP لـ Claude Desktop و Claude Code:
  ```bash
  claude mcp add reverse-api-engineer -- python /path/to/rae-bridge.py mcp
  ```

## الطريقتان (تبويبان في النافذة)

### 1. محلي
النافذة تكلّم الجسر على جهازك مباشرة. الاستهلاك صفر، وتعمل من الكمبيوتر الذي يشغّل الجسر فقط. ومن Claude Desktop أو Claude Code على نفس الجهاز عبر `python rae-bridge.py mcp`.

### 2. عبر claude.ai (ntfy)
تطلب من Claude في claude.ai (أي متصفح أو الهاتف)، والتنفيذ على جهازك:

1. Claude يستدعي `rae_relay_capture` في خادم MCP الخاص بالمنصة.
2. المنصة ترسل رسالة **مشفّرة** إلى قناة سرية في ntfy.sh (مجانية).
3. الجسر مستمع لتلك القناة (وليس للمنصة)، فيشغّل الأداة محلياً.
4. الجسر يبلّغ المنصة مرتين: «بدأت» ثم «انتهيت» مع الكود (`/api/rae/relay`).
5. Claude يقرأ النتيجة بـ `rae_relay_result` (وتحسين الكود بـ `rae_relay_engineer`).

**الإعداد:**
1. اصنع سراً من تبويب «عبر claude.ai»، وضعه في Vercel باسم `RAE_RELAY_SECRET`، ثم Redeploy.
2. شغّل الجسر: `python rae-bridge.py --origin https://<موقعك> --relay <السر>`.
3. منصتك مضافة في claude.ai كـ connector (`https://<موقعك>/api/mcp`).

**الاستهلاك لكل تشغيل:** بين 5 و10 طلبات Vercel قصيرة، وقاعدة البيانات تستيقظ دقائق قليلة، والنتيجة تُحذف بعد يوم. أثناء الانتظار صفر، لأن الجسر لا يسأل المنصة.

**التشفير:** الجسر بمكتبة Python القياسية فقط (بلا AES)، فالرسائل مختومة بـ HMAC-SHA256 في وضع العدّاد مع وسم مصادقة (encrypt-then-MAC)، ونفس البناء في المنصة. ntfy يرى نصاً مشفّراً فقط، واسم القناة مشتق من السر، والطلبات المكررة أو الأقدم من ساعة تُتجاهل. خادم ntfy خاص: `--ntfy` في الجسر و `RAE_NTFY_URL` في Vercel.

## الحماية

- الجسر يستمع على جهازك فقط (127.0.0.1)، ويقبل طلبات موقع منصتك فقط، وكل طلب يحتاج رمز الربط (`~/.spir-rae/token`).
- **لا يشغّل الكود الناتج:** كود كتبه الذكاء الاصطناعي، فراجعه ثم شغّله بنفسك.
- **ممنوع:** إنستقرام وتيك توك وفيسبوك وثريدز وواتساب: واجهاتها الداخلية ليست للاستعمال دون إذنها، والمنصة تقرأها بطرقها العامة.
- المتصفح الافتراضي منفصل بلا حساباتك. وضع «Chrome الحقيقي» يعطي الوكيل جلساتك المسجّلة، فاستعمله بحذر.
- احترم شروط كل موقع وحدوده. التسجيلات قد تحتوي ملفات تعريف الارتباط والرموز، فلا تشاركها.

## من الكود إلى أداة في المتجر

الكود الناتج يبقى على جهازك. إن كان مفيداً، أعطه لـ Claude في جلسة على المستودع ليحوّله إلى أداة رسمية في المتجر (قراءة آمنة، واحترام robots.txt، وحد للسرعة، واختبارات).
